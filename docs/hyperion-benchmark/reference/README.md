# Reference captures

**Nothing else in this folder is committed.** The briefs link to each vendor's own page, and the
stills and clips you capture from their software are theirs, not ours — this repository is public and
AGPL. So the links live in the briefs, the captures live here on disk, and `.gitignore` keeps them
out of the history. Capture from your own licensed installs or from the public pages the briefs link
to.

Name a capture after the brief so the scoring script and a reader find it without being told:

```
reference/S3-opening-range.png
reference/V2-bookmap-heatmap.png
reference/V2-bookmap-heatmap.mp4      # where motion is the point
```

## What a capture has to show

A screenshot is the target, so it has to contain the thing being scored. For each brief the
**Visual target** paragraph is the checklist; the capture must show all of it in one frame, at a
realistic density — a footprint with six bars on screen proves nothing about a picture that has to
survive sixty.

Capture a **video** rather than a still for the three where change over time is the feature: the
heatmap (V2), the ladder (V4) and the tape (V6). A still of a heatmap is a still of a bitmap; what is
being judged is whether a pulled order stops drawing.

## Fair use

These are used privately, to judge our own output against, and are never redistributed or embedded in
anything we publish. If a capture ever needs to appear in a public document, take the equivalent from
the vendor's own marketing page, with attribution and a link — that is what those pages are for.
